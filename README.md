# Клятва Северной Стали

Небольшой 3D-прототип для ПК на Kotlin + libGDX: рыцарь защищает северную крепость от пяти красных разбойников. Это вертикальный срез, который можно быстро расширять до релизной версии для VK Play.

## Игровой цикл

- `WASD` — перемещение по арене;
- `SPACE` — удар мечом;
- `F2` — перезапуск после поражения;
- победите всех пяти врагов.

Камера — третье лицо, арена и персонажи собраны процедурно из 3D-примитивов, поэтому внешние ассеты для запуска не нужны.

## Запуск

Требуется JDK 17+ и Gradle 8+:

```bash
gradle :desktop:run
```

Сборка дистрибутива:

```bash
gradle :desktop:distZip
```

Запускной класс: `com.knightgame.DesktopLauncherKt`.

## План перед публикацией в VK Play

1. Заменить примитивы на лицензированные модели рыцаря, врагов и окружения.
2. Добавить главное меню, настройки графики/звука, сохранения и поддержку русского/английского языков.
3. Вынести баланс, карту и тексты в JSON, добавить звуки и музыку с подтверждёнными лицензиями.
4. Настроить Gradle-пакет под Windows (JRE/нативные библиотеки), иконку, версию и тестовый стенд VK Play.
5. Добавить телеметрию только после согласования политики приватности и требований площадки.

Проект намеренно является стартовым playable-прототипом, а не готовым коммерческим релизом.
